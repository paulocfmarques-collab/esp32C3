# ESP32-C3 Gateway Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- LCD dashboard with clock, status, network, system, and saved Wi-Fi pages.
- Web portal for Wi-Fi provisioning and device info.
- UDP command processor for remote control.
- NTP synchronization with timezone and DST persistence.
- Weather integration using Open-Meteo.
- RGB LED feedback and animation modes.
- OTA update flow with progress rendering on the display.
- Idle matrix-style screensaver.

### Changed
- Improved repository documentation and project presentation.
- Consolidated the project description around the ESP32-C3 gateway workflow.

### Notes
- The firmware is designed for the ESP32-C3 Arduino environment.
- A complete production release log can be added here as version tags are created.
